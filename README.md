# TradeIO

TradeIO is a senior design project focused on developing an AI-assisted trading journal and behavioral analytics platform.

The project will explore trade tracking, performance analysis, risk management, trading behavior, and AI-assisted insights to help traders better understand their decisions and improve discipline over time.
